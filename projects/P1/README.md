# P1 · 介质透射窗口

**你的任务：只调整一块均匀介质板的厚度，让它在 300 GHz 附近更透明，并说明为什么。**

这是第一个独立设计项目。先把一个小模型从物理假设做到可信结果，再逐步加入参数探索和几行手写代码。用理想材料练基本功；后续项目再引入真实太赫兹材料的色散和损耗。

## 先做这一小步

今天先花约 20–30 分钟，画一张空气—介质板—空气的侧视草图，或用文字说明：

1. 波从哪边来，沿哪个方向传播，电场指向哪里？
2. 哪个尺寸是本次设计变量？其余设置为什么先保持不变？
3. 你准备观察什么量判断“更透明”？改变厚度后，你预计它怎样变化？不确定的地方可以直接写“不确定”。

估一下 300 GHz 对应的自由空间波长，再打开 CST 创建工程、设定单位和参数。**本轮先做到基础模型与设置方案，不急着搜索最佳厚度。**把草图、方案或卡住的位置带回对话，我们按需要补工具教学。

## 目标与范围

| 项目 | 本次约定 |
| --- | --- |
| 物理对象 | 空气中的横向无限大、均匀平行介质板，正入射；不是有限小方片的散射问题 |
| 材料 | 教学用理想各向同性介质，εr = 4、μr = 1；电导率与介质损耗均为 0，无色散 |
| 初始厚度 | `d = 170 μm`，用于获得第一条基线曲线 |
| 可调整范围 | `80 ≤ d ≤ 400 μm`；主任务只改厚度 |
| 观察频段 | 200–400 GHz，重点看 `f0 = 300 GHz`；300 GHz = 0.3 THz |
| 设计目标 | 找到 `T(300 GHz) ≥ 0.95` 的厚度，并与初始设计比较 |
| 数值检查 | 无损模型的 `R + T` 应接近 1；本项目先以最大偏差 0.01 为排查参考，不能仅凭这一项认定结果正确 |
| 最终解释 | 说明厚度如何改变透射，以及高透射是否覆盖整个频段；用曲线和至少一项物理对照支持解释 |

这里的 `T` 是透射**功率比例**，不是振幅，也不是 dB 值。总反射、总透射要包含本次入射激发的所有传播模式；如何读端口和模式见[工具卡](工具卡.md)。

目标的可达性已用无损平板解析关系检查，边界与端口方法已核对 CST 2025 本机帮助。具体目标厚度由你探索。备课检查不作为你的学习实验或能力证据。

## 分四轮推进

### 第一轮：把物理问题变成模型

完成上面的草图和预期，建立参数化厚度与介质材料，解释横向边界和入射端口代表什么。初次设置采用工具卡给出的简单方法，不需要独自发明端口配置。

留下一份可继续修改的 `.cst` 工程；边界或端口有疑问时先讨论设置，不要求盲试。

### 第二轮：拿到可信的基线

先在同一个模型中把介质的 εr 临时设为 1，做空气对照。说说此时预期的 R、T，实际结果不符就先检查设置。然后恢复 εr = 4、d = 170 μm，得到初始频谱。

保留原始 S 参数数据，至少读清楚 300 GHz 附近的反射与透射。解释曲线纵轴和归一化方式；不要把低反射自动理解成高吸收。

### 第三轮：用自己的策略改善设计

提出下一次准备试的厚度和理由，运行、比较，再决定下一步。先用少量手动尝试观察趋势；约 6–10 次有理由的尝试足以开始讨论策略，次数不是硬性限制或评分标准。

找到较好的候选后，保存与初始厚度的对照图。若一直不见改善，可以求助一个提示，而不是直接索取全套参数。第一轮优化使用自己的判断，不需要 GA、自动扫参或 agent 批量调度。

### 第四轮：验证、解释、做一点代码

围绕自己的候选做三件事：

- **数值对照：**在基线和候选中的至少一个模型上做一次实际网格细化，比较 300 GHz 的 T 和主要频谱特征。本项目可先把 `|ΔT| < 0.01` 作为实用观察尺度；若不满足，先解释或继续细化。增加曲线显示点数不等于细化网格。
- **物理对照：**在已有尝试后，再结合单界面反射与板内传播建立简化解析计算，比较几个频点。先讨论你已经看到的规律，再按需要推导，不提前给出目标厚度公式。可增加一张有明确观察目的的电场图。
- **手写小练习：**读懂一次创建介质板的 History 代码，指出名称、材料、几何范围和参数表达式；在单独练习中手动重组或改写几行。再亲手写出或改写从导出数据计算功率比例的几行 Python，并说明每行在做什么。第一次绘图允许先使用 CST 自带功能。

最后做一个很小的迁移：改变目标频率、材料参数或入射偏振之一。先给预期，再验证。具体变式等主任务完成后选择。
