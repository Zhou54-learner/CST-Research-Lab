## 1. 开始前需要的几个概念

| 名称 | 本项目中怎么用 |
| --- | --- |
| Geometry / Frequency units | 建议几何用 `μm`，频率用 `GHz`。几何参数填 170 表示 170 μm；频率填 300 表示 300 GHz |
| Parameter | 把厚度写成参数 `d`，几何范围引用 `d`。以后改参数，不重新画整个结构 |
| Relative permittivity / permeability | `εr` 和 `μr` 是相对介电常数和相对磁导率，均无量纲；这里分别为 4 和 1 |
| Material loss | 理想无损意味着电导率与介质损耗都设为 0；不要从材料库随便挑一个同名真实材料替代 |
| Background | 板外为空气，本项目用 εr = μr = 1 的无损背景近似 |
| Port / mode | 端口代表入射和出射的通道；模式描述这个通道的场形状与偏振。先看清楚模式，再选曲线 |

可用 `λ0 = c / f` 估量级；无损非磁性均匀介质中 `n = √εr`。这两条先用于检查尺寸与单位，不急于推导最佳厚度。

**一个局部参数例子：**若某个练习块的宽度参数叫 `w`，把 X 范围写成 `-w/2` 到 `w/2`，就能保持居中。请自己想出板厚对应的 Z 范围，并解释改动 d 后哪一面移动。

## 2. 把无限平板放进一个小计算区域

**当前工程的模板调整（2026-11-11）：**已保存工程来自色散图模板（Dispersion Diagram），当前为本征模求解器（Eigenmode Solver）。先关闭现有求解器参数窗口（Close），切换到顶部 `Home`（主页）选项卡，再点击 `Setup Solver`（设置求解器）文字旁的向下小三角，选择 `Frequency Domain Solver`（频域求解器）。本机帮助的 Home 功能区截图显示该按钮带下拉箭头。注意：`Home → Simulation → Setup Solver` 中的 Simulation 是 Home 页内的功能组；不是顶部的 Simulation 选项卡。直接点击顶部 Simulation 页中的 Setup Solver 按钮，会打开当前求解器的参数窗口，不能据此切换求解器。打开求解器设置后，网格类型（Mesh type）选 `Tetrahedral`，方法（Method）选 `General purpose`；先完成设置，不点击 `Start`（开始求解）。

随后逐项核对下表。原模板还带有 X/Y 周期相移（Periodic phase shift）、Z 向电壁（Electric）和参数扫描（Parameter Sweep）：改为本项目的 Unit Cell / Open 与正入射设置；在 Parameter Sweep 中选中旧的 `Sequence 1`，用 `Delete`（删除）移除该扫描序列，保留几何与厚度参数 `d`。`PathPara`、`phaseX`、`phaseY` 先留着，待确认当前设置不再引用它们后再整理。频率范围（Frequency Range）设为 200–400 GHz。横向尺寸当前误设为 2000 × 2000 μm，需在长方体属性（Brick / Properties）的 `Xmin / Xmax` 和 `Ymin / Ymax` 改为 −100 / 100；厚度 `Zmin = 0`、`Zmax = d` 可保留。

推荐本项目使用 **Frequency Domain Solver（频域求解器）+ Unit Cell（单元边界）+ Floquet ports（Floquet 端口）**。均匀板截取任意一小块，再在横向重复，会还原无限平板。这个方法可继续用于 P2；P1 先理解正入射和基本模式，不展开衍射理论。

提供以下起步约定，帮助你把注意力放在物理与设计上：

| 设置 | 起步选择及理由 |
| --- | --- |
| 坐标 | 按你的初步方案：板面平行 XY，传播沿 −z，从 Zmax 向 Zmin；x 线偏振 |
| 横向小块 | X、Y 各取 200 μm，介质填满横向截面；这不是一块边长 200 μm 的孤立器件 |
| X/Y 边界 | Unit Cell，矩形网格、Fit unit cell to bounding box；法向入射时横向相移为 0 |
| Z 边界 | 两侧 Open；与横向 Unit Cell 配合时，在 Zmin/Zmax 形成 Floquet 端口 |
| 板外空气 | 两侧各留约 250 μm 作为固定起步值，使用背景空间设置；不要同时再加一套含义相同的空气余量 |
| 入射角 | θ = 0°、φ = 0°；本轮只做法向入射 |
| 端口模式 | 每侧先保留两个零阶正交线偏振基本模式；起步使用包含 Floquet 的全部端口/模式激励选项（All+Floquet）。求解器分别激励各模式；分析时只取 Zmax 的 x 线偏振入射模式对应的结果，查看场箭头确认偏振，不预先认定模式编号 |
| 求解 | 四面体网格、通用频域扫描，200–400 GHz；启用自适应网格，保留求解日志 |
| 300 GHz | 在频率采样设置中加入 300 GHz 单点，便于直接检查目标频率；宽带频谱仍保留 |

在当前小周期、空气端口和频段下，只需要考虑两种零阶传播偏振；均匀各向同性板正常情况下不会把能量转成正交偏振。仍应查看交叉项，确认实际设置符合预期。

全部模式求解会多算几种入射情况，不意味着把它们同时叠加照射。只比较同一个入射模式对应的一组输出；不要将不同入射条件的功率混加。这个起步方式已在本机通过求解检查；以后需要减少计算量时，再单独检查指定激励的设置。

常见入口：`Simulation → Settings → Boundaries`，其 `Unit Cell`、角度等页签说明边界；`Background` 定义背景空间；Floquet 模式设置随单元边界提供。若找不到某个入口，告诉我当前对话框名称或提供局部截图，我会只补这一项。

这是给定的起步模型方法，不是要求你记住一整套按钮。开始前至少能解释：横向重复了什么、Z 方向哪里入射、端口离板多远。

## 3. 读对曲线，比“有结果”更重要

Floquet 结果名通常包含两侧端口与模式，例如 `SZmin(1),Zmax(1)`。其含义是“激励 Zmax 的模式 1，观察 Zmin 的模式 1”；前面是输出，后面是输入。实际名称和模式编号以结果树、端口模式场图为准，不把模式 1 永久当成某个固定偏振。你的方案中反射在 Zmax 一侧，透射在 Zmin 一侧；原先工具卡以相反入射方向举例，本次已按你的选择统一。

在本项目空气端口、功率归一化且只比较传播模式时，对固定的入射模式 a：

```text
R = 所有反射传播模式 |S(out,a)|² 的和
T = 所有透射传播模式 |S(out,a)|² 的和
```

确认交叉偏振可忽略后，才可用同偏振反射与透射的平方近似总 R、T。CST 若显示线性振幅 `|S|`，需要平方；若显示 `20 log10|S|` 的 dB 数，则功率比例是 `10^(dB/10)`。不能直接平方一个 dB 数。

无损对照检查 `R + T ≈ 1`。若结果不满足，先定位归一化、模式遗漏或数值问题；差额不能直接命名为“吸收”。另一个基本检查是空气对照：把 εr 设成 1 后，模型应接近没有介质界面的情况。

先在 CST 中查看曲线和数值，记录实际曲线名称、纵轴含义和对应激励。再将结果导出为 ASCII/TXT/CSV；导出后先打开文件看表头、列和单位，不假设它一定是频率加线性振幅。需要处理脚本时，把前几行格式拿来讨论。

## 4. History List：先读一小段

找到创建几何的历史条目，辨认 `.Name`、`.Component`、`.Material`、`.Xrange`、`.Yrange`、`.Zrange` 和 `.Create`。它们是 CST 的 VBA 风格命令，不是 Python 语法。

例如一个练习块的两条命令：

```vb
.Xrange "-w/2", "w/2"
.Zrange "0", "h"
```

引号中的 `w`、`h` 是交给 CST 计算的参数表达式。请在自己工程中找出类似语句，解释参数值、表达式与几何操作的区别。先理解再复制；完整块还依赖对象、材料、组件等上下文。

若用 Python 组织一段命令文本，最小练习可以只是生成并打印字符串：

```python
height = 12
command = f'.Zrange "0", "{height}"'
print(command)
```

这段例子不会启动 CST。试着比较输出中的数字 `12` 与上面字符串参数 `"h"` 的区别；后续再把你理解的几块命令组织起来。

读复数数据时，功率计算的局部练习是：

```python
s = complex(0.3, 0.4)  # 纯示例数值，不是你的仿真结果
power_fraction = abs(s) ** 2
print(power_fraction)
```

在确认自己导出的列含义后，再改写为读取真实数据。CSV 读取、数组和绘图只在需要时逐项教，不直接提供整个处理工程。
