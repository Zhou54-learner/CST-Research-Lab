## 验证范围

基础设施模型为理想直矩形波导，截面 22.86 × 10.16 mm，8–12 GHz，单模波导端口，理想电壁，时域求解。它用于检查环境与数据通路，既不代替太赫兹器件训练，也不提前给出 P1 模型。

1. **解析闭环：**生成理想 TE10 传播的复数 S 参数，保存 CSV、指标、图表与运行记录，生成 HTML。
2. **真实 CST 闭环 A：**新建独立实例和 10 mm 模型，运行求解器，保存工程，导出结果并更新页面。
3. **真实 CST 闭环 B：**改为 12 mm，再次独立建模求解；除功率检查外，将复数透射结果与对应长度的解析传播比较，防止只检查“有数据”或重复使用旧结果。
4. **记录与页面：**核对原始数据和摘要、文件摘要、状态和 HTML 一致性；验证非法输入和过期页面可被识别；检查桌面与手机布局、标签页、项目详情、对照图和本地链接。

预先设定的基础检查：最大反射功率 < 0.01，最大功率平衡误差 < 0.02；额外验收要求复数 S21 与解析传播的最大绝对误差 < 0.02。这些是基础设施算例的判据，不作为未来设计项目统一精度标准。详细实测值由运行记录给出。

首批 10 mm 与 12 mm 实测各导出 1,001 个频点，最大功率平衡误差分别约 0.0203% 和 0.0213%，复数 S21 最大绝对误差分别约 0.00258 和 0.00294，均通过上述判据。原生求解日志显示能量衰减停止条件满足，GPU 加速关闭。后续复测继续保留独立运行记录。

随后再次执行 10 mm 工程，导出指标与第一次一致，并完成原生求解日志归档。首版累计保存 1 次解析基线、3 次真实 CST 运行。非法输入拒绝、缺少配置时的失败记录、过期页面检测均在隔离测试中通过；桌面 1440 × 1080 与手机 390 × 844 页面交互通过，无 JavaScript 错误和外部网络请求。

项目已推送至指定 GitHub 仓库的 `main`。首次提交 `6040ae3` 从远端重新克隆后，再次通过 11 个路线节点、4 份运行记录、所有证据文件摘要和页面一致性检查。以后按阶段提交推送，未启用后台自动同步。

每个真实运行保留 `.cst`、History 命令、复数 CSV、执行日志、图表、对应工具源码和 SHA-256。CST 归档工程首次打开会解包工作数据；CSV 可直接查看，无需打开 CST。

## 适用边界与下一步

通过这些测试能够确认小型时域工程的建模、求解、提取与归档通路。它不能证明所有求解器许可证、热场、GPU 加速、太赫兹材料模型和大型优化可用；这些在相应项目开始前用小问题检查。

当前内存条件下从单元级、小参数空间开始。首版没有 MCP 服务、常驻 agent、后台学习监测或自动推送；这与路线的分阶段实施一致。学习者能力仍为“未观察”，不是零基础，也没有因基础设施通过而自动升级。

闭环验收后进入 P1 任务设计：只确定目标、必要背景、工具示例与交付形式，实际设计与关键操作由学习者完成。

# 浏览器验收使用已有 Playwright 与 Chrome；此依赖仅用于页面开发检查
